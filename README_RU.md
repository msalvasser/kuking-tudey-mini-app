# КУКИНГ ТУДЕЙ — Telegram Mini App

Это первая статическая версия Mini App для Telegram.

## Что уже внутри

- 43 рецепта из нашей книги.
- Стилизация карточек в духе твоих референсов: editorial / playful / collage, а не «тарелка в кружке».
- Разделы: **Сегодня / Рецепты / Закупка / Сохранённое**.
- Поиск и фильтры.
- Полная карточка рецепта.
- «＋ В закупку».
- Постоянная база продуктов.
- Избранное.
- Добавление собственных рецептов.
- Экспорт и импорт своих рецептов в JSON.
- Данные пользовательских рецептов, избранного и закупки сохраняются локально на устройстве через localStorage.
- Поддержка Telegram WebApp SDK: тема Telegram, кнопка Back и safe-area для телефона.

## Важное ограничение этой первой версии

Пока это **frontend-only MVP**. Новые рецепты и закупка сохраняются на конкретном устройстве, а не в общей облачной базе. Это специально сделано, чтобы первый запуск был максимально простым.

Для будущей масштабной версии мы вынесем данные в backend/database. Тогда рецепты, избранное, синхронизация между устройствами, аккаунт пользователя и совместная книга будут серверными.

# Как запустить впервые

## Вариант A — самый простой: GitHub Pages

Для Telegram Mini App нужен публичный HTTPS-адрес. GitHub Pages подходит для такого статического MVP.

1. Создай аккаунт на GitHub: https://github.com/
2. Создай новый **public repository**, например:
   `kuking-tudey-mini-app`
3. Распакуй этот ZIP.
4. Загрузи в repository:
   - `index.html`
   - папку `data`
   - `.nojekyll`
5. Открой **Settings → Pages**.
6. В разделе **Build and deployment** выбери:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
7. Нажми **Save**.
8. GitHub покажет адрес примерно такого вида:

   `https://ТВОЙ-USERNAME.github.io/kuking-tudey-mini-app/`

Дай GitHub несколько минут на публикацию.

## Как подключить к Telegram

1. В Telegram открой **@BotFather**.
2. Создай бота через `/newbot`, если его ещё нет.
3. Открой настройки созданного бота.
4. Выбери **Bot Settings → Configure Mini App → Enable Mini App**.
5. Укажи URL опубликованного `index.html`.
6. Для удобного запуска настрой **Menu Button** и выбери URL Mini App.
7. Назови кнопку, например: `КУКИНГ ТУДЕЙ`.

Telegram официально поддерживает запуск Mini Apps через Menu Button и Main Mini App. URL Mini App должен быть доступен по HTTPS.

# Как вносить изменения потом

Есть два типа изменений.

## 1. Изменить рецепты

Основные рецепты находятся здесь:

`data/recipes.js`

Внутри лежит массив:

`window.COOKING_TODAY_RECIPES = [...]`

Каждый объект содержит примерно:

- `n` — название
- `e` — emoji
- `time` — quick / normal / cook / prep
- `p` — белок/категория
- `type` — dish / prep / sauce / side / dessert
- `mins` — минуты
- `k` — примерные ккал
- `m` — БЖУ
- `density` — плотность
- `tags` — теги
- `d` — описание
- `ing` — ингредиенты
- `steps` — шаги приготовления

Пример:

```js
{
  n: "Моя паста",
  e: "🍝",
  time: "normal",
  p: "chicken",
  type: "dish",
  mins: 30,
  k: "550",
  m: "Б 35 · Ж 18 · У 62",
  density: "B",
  img: "",
  tags: ["паста", "курица"],
  d: "Короткое описание.",
  ing: ["300 г курицы", "250 г пасты"],
  steps: ["Нарезать курицу.", "Обжарить.", "Добавить пасту."]
}
```

После изменения файла просто загрузи новую версию в GitHub и нажми **Commit changes**. GitHub Pages автоматически опубликует новую версию.

## 2. Изменить дизайн или функциональность

Вся основная логика и стили сейчас находятся в:

`index.html`

Там можно менять:

- цвета;
- шрифты;
- карточки;
- навигацию;
- фильтры;
- модальные окна;
- форму добавления рецепта;
- закупку;
- сохранённые рецепты.

**Рекомендация:** рецепты менять только в `data/recipes.js`, а интерфейс — в `index.html`. Так мы не будем снова смешивать данные и дизайн и случайно терять каталог.

# Как добавить рецепт прямо из Telegram

В Mini App есть кнопка:

**＋ Добавить новый**

Заполняешь:
- название;
- описание;
- время;
- категорию;
- ингредиенты;
- шаги.

После сохранения рецепт сразу появляется в приложении.

Пока он хранится только на твоём устройстве. Для будущего полноценного приложения мы заменим localStorage на базу данных.

# Как тестировать изменения

Самый простой цикл:

1. Изменила `index.html` или `data/recipes.js`.
2. Загрузила файл в GitHub.
3. Commit changes.
4. Подождала публикацию.
5. Открыла Mini App в Telegram.

Если Telegram показывает старую версию, сначала полностью закрой Mini App и открой заново. Для разработки можно также открыть опубликованный HTTPS URL в обычном браузере.
